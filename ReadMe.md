# Full Stack Blog Application

A full-stack blog application built with React, Node.js, and Express.

## Features
* Browse and read articles organized by categories
* Featured section for important posts
* Admin users can create and publish new posts
* Readers can leave comments on articles
* Dark/Light mode toggle
* User authentication (Login/Register)

## Technologies Used
*  "Frontend:" React, Tailwind CSS, Vite
*  "Backend:" Node.js, Express
*  "Database:" JSON file (db.json)
*  "Icons:" Lucide React

## How to Run Locally
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:3000`

## Project Structure
* `src/components` : React components
* `src/data/db.json` : Database
* `server.js` : Backend server
* `vite.config.js` : Vite configuration
